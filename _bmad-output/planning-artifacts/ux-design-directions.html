LEBOv2 Phase 2 — UX Design Directions

Direction 1: "Focused Instrument" — Extend Phase 1 dark-gold vocabulary with Phase 2 capabilities
Selected Direction
Design direction chosen: Extend the Phase 1 dark-gold aesthetic. Phase 2 adds three new surface types (item slot cards with tier pips, optimization master slider with gradient track, skill picker grid) using the same visual vocabulary. The Glass Cannon ↔ Juggernaut gradient slider is the single bold visual innovation of Phase 2 — everything else is invisible infrastructure.
